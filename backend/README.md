# TaskHub

A multi-tenant task management system built with Express, React, and PostgreSQL.

## 📋 Overview

TaskHub allows multiple organizations to use the same app while keeping their data completely separate.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- PostgreSQL (v12+)
- Git

### Installation

```bash
cd backend
npm install
cp .env.example .env
npm run dev
```

Visit: http://localhost:3001
